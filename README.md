# RGB-to-Grayscale Accelerator Projects

This repository is split into two independent projects:

| Project | Purpose | Main requirement |
|---|---|---|
| [`base-accelerator/`](base-accelerator/README.md) | Original SystemC/TLM software model | SystemC and CMake |
| [`hls-image-accelerator/`](hls-image-accelerator/README.md) | Vitis HLS IP, Vivado platform, and Vitis bare-metal software | AMD Vitis HLS/Vivado/Vitis 2024.1 |

Each project has its own source tree, build outputs, scripts, and README.
Build and run commands must be executed from the selected project directory.
